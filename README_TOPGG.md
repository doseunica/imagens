# JujutsuBotKaisen — imagens para Top.gg

Estas são as quatro capturas enviadas para a página do bot no Top.gg. Os PNGs foram preservados sem recorte ou recompressão.

## Arquivos

- `loja.png` — painel da loja (`.shop`)
- `inventario.png` — inventário (`.inv`)
- `status.png` — ficha/status do jogador (`.status`)
- `missao-combate.png` — painel de combate de missão

## Importar em `doseunica/imagens`

Extraia os arquivos deste ZIP e envie `loja.png`, `inventario.png`, `status.png`, `missao-combate.png` e este README para o repositório público `https://github.com/doseunica/imagens` usando **Add file → Upload files**.

Depois do commit em `main`, as URLs públicas serão:

- https://raw.githubusercontent.com/doseunica/imagens/main/loja.png
- https://raw.githubusercontent.com/doseunica/imagens/main/inventario.png
- https://raw.githubusercontent.com/doseunica/imagens/main/status.png
- https://raw.githubusercontent.com/doseunica/imagens/main/missao-combate.png

Use as URLs `raw.githubusercontent.com` na galeria/descrição do Top.gg para exibir os PNGs diretamente.
